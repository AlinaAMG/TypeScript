
## Drag & Drop Project (TypeScript)

## Over dit project
Dit project is een oefening in TypeScript met een drag-and-drop functionaliteit.
Het richt zich op moderne ES6 modules, OOP-principes, en TypeScript features voor een onderhoudbare en goed gestructureerde codebase.

## ✨ Features

TypeScript Decorators → voor validatie en automatisering van logica.

DOM Manipulatie & Event Listeners → dynamisch creëren van elementen en luisteren naar gebruikersinteracties.

Form Validation → controle van gebruikersinput met duidelijke regels.

ES6 Modules → code opsplitsen in meerdere bestanden met import en export.

Classes & Types → OOP-principes met sterke typecontrole.

Getters & Setters → gecontroleerde toegang tot class properties.

Interfaces → contracten voor objectstructuren.

Enums → handig gebruik voor statusbeheer (Active vs Finished).

Generics → herbruikbare en flexibele state management.

Union Types → voor waarden die meerdere types kunnen hebben.

Schaalbare projectstructuur → overzichtelijke mappen en modulair design.
